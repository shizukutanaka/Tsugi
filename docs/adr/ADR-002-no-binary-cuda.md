# ADR-002: バイナリCUDA変換を採用しない（法的回避）

- 日付: 2026-06-15
- 状態: Accepted（不可逆・最優先遵守）

## 状況

CUDA移植の手段に「既存CUDAバイナリ/PTXをそのまま非NVIDIA GPUで動かす変換層」（ZLUDA型）がある。魅力的だが法的リスクを検証。

## 決定

**バイナリCUDA変換層を一切作らない。新DSL（Tsugi Tile DSL）またはソースレベル変換（公開ドキュメント準拠）のみ。**

## 根拠

1. **NVIDIA EULAが翻訳層を禁止。** 2021年以降CUDA EULAに「他プラットフォームへの翻訳層経由実行禁止」条項。CUDA 11.6（2024年3月頃）でインストール同梱ドキュメントに明文化。
2. **ZLUDA実例: AMDが法的理由で撤回。** AMDが2022-2024にZLUDAを資金援助したが、法的理由で打ち切り、AMD法務がリリース済みコードのロールバックを2024年8月に強制。前例として重大。
3. **ソースレベルは安全。** chipStar・HIP は公開API仕様と開放標準（SPIR-V/OpenCL/Level Zero）を使うソースレベル変換で合法運用。バイナリ逆コンパイルを避ける。
4. **Tsugiの戦略はそもそもCUDA変換に依存しない。** 楔はPyTorch（torch.compile）層。CUDAソースを動かす必要がない。

## 却下した代替案

- **ZLUDA型バイナリ変換**: EULA違反・AMD撤回前例。却下。
- **PTX→AMDGCNバイナリ変換**: 同上の法的リスク。却下。
- **CUDAソース→Tsugi自動変換（HIPIFY型）**: v0.1スコープ外だが将来検討可（合法・公開ドキュメント準拠なら）。保留。

## 結果

法的リスクをゼロに保つ。万一CUDA移植ツールを将来作る場合も chipStar 流（ソースレベル・公開ドキュメント）に限定。

絶対禁止リストに追加: バイナリCUDA変換。
