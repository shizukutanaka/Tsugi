== ソクラテス問答で発見した新視点 ==
既存4視点(portability/tolerance/feasibility/propagation)は全て *デプロイ前の静的検証*。
等価性は scale/cond/K の前提下で「認証」されるが、本番は oracle も第2ベンダーも無く
AMD単体で未知入力が流れる。発散はデータ依存(propagation)なので、本番入力が認証
エンベロープを逸脱すると静的保証が静かに無効化される。
→ 静的証明を一度きりで信じず「認証エンベロープ + 実行時に前提を検算する契約」へ。
docs/PERSPECTIVE-runtime-envelope.md に記録。

== 検証の全体像(5視点) ==
時間軸: 静的(デプロイ前) → 動的(本番)
